de devolución

Consulta un pedido, revisa si cumple las condiciones y aprueba o rechaza la devolución. Puedes simular un fallo y comprobar qué ocurre al reintentar.

Sobre este ejemplo

Una tienda ficticia, siete casos de prueba y un registro de las operaciones.

El sistema aplica reglas fijas. Los pedidos y recibos son de prueba; no se realizan devoluciones reales ni se consulta un modelo de IA.
