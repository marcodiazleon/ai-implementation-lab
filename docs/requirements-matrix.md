# Requirement matrix · Matriz de requisitos

Generated by `python scripts/requirement_matrix.py --write` from acceptance.csv and case-kinds.json (R51, D42). Do not edit by hand. Each requirement lists its observable behavior, the code behind it, its positive and negative or limit cases with kind, status and the evidence recorded for the version in the `product_version` column. Structural cases (text or markup inspection) are marked and never count as the behavior-level positive. Manual cases keep their recorded status; nothing here is marked executed by inspection. Overrides of the classification floors (D44), if any, are listed under Open items.

Kinds: behavior = executes code and checks results; structure = inspects markup, text or files; document = validator over the records; manual = a person or a recorded browser run.
